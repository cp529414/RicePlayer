隱私權政策

播放與本機資料

RicePlayer 會開啟你選擇的媒體與字幕。播放進度、App 偏好設定與已儲存的分享設定會保存在裝置上。使用 RicePlayer 無須註冊帳號。播放的影片不會為了顯示橫幅廣告而傳送給廣告供應商。

Pro 版的 RiceNetwork

使用 RiceNetwork 時，裝置可能會交換網路位址、裝置名稱、配對資訊和連線工作階段資料，以便尋找彼此並建立連線。經核准的接收端可存取你提供的媒體、中繼資料和字幕。你可以在 App 內停止分享或移除已儲存的連線。

廣告與隱私選項

iPhone 和 iPad 免費版啟用廣告時，Google Mobile Ads 會提供橫幅廣告，Google User Messaging Platform 則處理適用的同意選項。RicePlayer 要求提供非個人化廣告，且不會要求 Apple 的追蹤許可。Google 可能處理 IP 位址、裝置識別碼、廣告資料、互動資料和診斷資訊，以投放及衡量廣告並防範詐欺。如果 App 內顯示隱私選項，你可以開啟該選項管理設定。

請參閱 Google SDK 的資料揭露說明及 Google 隱私權政策。Pro 版及 Mac 和 Apple Vision Pro 的原生版本均未包含 Google 廣告 SDK。

App Store 購買項目

款項由 Apple 處理。RicePlayer 使用 App Store 的交易和購買權益資訊，判斷你是否可以使用已購買的功能。請參閱 Apple 隱私權政策。

網站託管

本網站由 GitHub Pages 託管。GitHub 可能處理包括 IP 位址在內的請求資訊，以提供網站服務並維護安全。請參閱 GitHub 隱私權聲明。

刪除資料與聯絡開發者

你可以在 App 內移除已儲存的連線，也可以刪除 App 以移除其本機資料。儲存在 App 以外的媒體會留在原本的位置。如有隱私相關問題或請求，可在 App Store 頁面提供開發者聯絡資訊時，透過該資訊聯繫開發者。一般問題可透過 GitHub 公開儲存庫詢問。請勿在公開貼文中張貼個人資料或私人媒體。
