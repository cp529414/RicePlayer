# RicePlayer

[English](README.md)

在 Mac、iPhone、iPad 和 Apple Vision Pro 上播放自己的影片。RicePlayer 支援 MP4、MOV 及相容的 MKV 檔案，可選擇音軌與字幕，並儲存播放進度。

- [RicePlayer 網站](https://cp529414.github.io/RicePlayer/zh-Hant/)
- [比較免費版與 Pro 版](https://cp529414.github.io/RicePlayer/zh-Hant/#editions)
- [使用 RiceNetwork 分享影片](https://cp529414.github.io/RicePlayer/zh-Hant/#sharing)
- [隱私權政策](https://cp529414.github.io/RicePlayer/zh-Hant/privacy/)
- [使用條款](https://cp529414.github.io/RicePlayer/zh-Hant/terms/)

**RicePlayer** 可播放本機檔案。啟用廣告時，iPhone 和 iPad 免費版可能會顯示橫幅廣告。

**RicePlayer Pro** 無廣告，並提供 RiceNetwork。若要透過區域網路串流，請在傳送端開啟**分享**並加入相容的影片，在另一部裝置上開啟**接收**，核對配對碼後再核准存取。

RicePlayer 可開啟你選擇的媒體，無須註冊 RicePlayer 帳號。隱私權政策說明本機資料、經核准的分享、Google 廣告與同意選項，以及 App Store 購買項目的資料處理方式。
